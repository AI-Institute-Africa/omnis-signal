API Reference

Complete developer reference for machine-to-machine integrations and external agents.

Swagger Interactive UI Docs ReDoc Clean API Schema Download AI & Agent Guide (.md)
Base URL: http://localhost:8002
GET /api/v1/agent/capabilities
Platform Capabilities Discovery

Returns a machine-readable manifest of active categories, ingestion content types, and dynamic routes. Run on agent startup to configure bindings.

curl http://localhost:8002/api/v1/agent/capabilities
POST /api/v1/agent/ingest
Ingest Research Item

Push scraped intelligence data, PDF summaries, or news article metadata directly into the system. Requires matched source_name.

curl -X POST http://localhost:8002/api/v1/agent/ingest \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Scaling LLM Reasoning with Monte Carlo Tree Search",
    "url": "https://arxiv.org/abs/2407.01234",
    "abstract": "We propose a novel approach to...",
    "source_name": "arXiv",
    "categories": ["llm", "agents"]
  }'
POST /api/v1/agent/query
Query RAG Analyst Agent

Ask natural language questions to prompt the vector-augmented intelligence analyst and get structured source-cited responses.

curl -X POST http://localhost:8002/api/v1/agent/query \
  -H "Content-Type: application/json" \
  -d '{"question": "Summarize today\u0027s LLM reasoning breakthroughs", "context_hours": 24}'
GET /api/v1/agent/sources/active
Lightweight Active Source Feed

Returns a lean configuration list of only active sources to crawl, including target domains and rate-limits. Recommended for scraper services.

curl http://localhost:8002/api/v1/agent/sources/active
GET /api/v1/sources
List and Filter Registered Sources

List, create (`POST`), toggle (`PATCH`), or delete (`DELETE`) research sources. Supports type/status query parameter filtering.

curl "http://localhost:8002/api/v1/sources?source_type=arxiv&is_active=true"
